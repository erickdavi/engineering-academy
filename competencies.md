# Matriz de competências

A validação exige explicação conceitual, implementação prática e resolução de problemas. Esta matriz pública descreve objetivos, não notas individuais.

| Competência | Evidência esperada |
|---|---|
| Linux | Interpretar métricas e investigar incidentes |
| Redes | Explicar fluxos TCP, DNS, TLS e roteamento |
| Python | Implementar e testar automações |
| SQL | Modelar, consultar e investigar desempenho |
| IaC | Provisionar recursos de maneira reproduzível |
| Kubernetes | Operar workloads e investigar falhas |
| SRE | Definir SLOs e observabilidade |
| Dados | Construir pipelines confiáveis |
| IA | Implantar e avaliar serviços de inferência |
