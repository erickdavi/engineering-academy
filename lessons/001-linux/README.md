# Missão 01 — Coletor de métricas Linux

Construir um agente Python que obtenha métricas de CPU, memória, disco e processos, estruturando os resultados em JSON.

## Fundamentos
- Kernel e espaço de usuário; chamadas de sistema; /proc e /sys.
- Processos, threads, CPU, load average e memória disponível.
- Inodes, descritores, permissões e cgroups.
- Python: funções, leitura de arquivos, estruturas de dados, exceções e testes.

## Critérios de aceitação
- Coletar métricas sem exigir root para a operação normal.
- Documentar unidades e significado de cada indicador.
- Tratar falhas de leitura e produzir JSON válido.
- Comparar resultados com ferramentas Linux e explicar diferenças.
- Implementar testes e defender as decisões técnicas.

Os materiais multimídia serão adicionados separadamente.
