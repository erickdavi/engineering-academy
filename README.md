# Engineering Academy — Livro didático

Formação dirigida por projeto em DevOps, SRE, Engenharia de Dados e Infraestrutura de IA.

## Como estudar

Leia o capítulo ou ouça a narração, revise com os flashcards e execute o laboratório quando estiver diante do computador. Cada missão integra fundamentos, implementação e validação do aprendizado.

## Projeto integrador

Plataforma experimental de AIOps, evoluindo de um coletor Linux até uma plataforma de dados e inferência.

Materiais didáticos públicos; avaliações individuais e informações pessoais permanecem fora do repositório. Os capítulos em Markdown são a versão navegável do livro. Arquivos binários devem ser versionados junto às aulas ou disponibilizados por links públicos permanentes, nunca por links temporários de chat.
