# Engineering Academy

Formação dirigida por projeto em DevOps, SRE, engenharia de dados e infraestrutura de IA.

## Metodologia
Aprender fundamentos diante de necessidades concretas do projeto, implementar, testar, investigar falhas e validar a compreensão antes de avançar.
